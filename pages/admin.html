รายการรายวิชา

ดึงข้อมูลจาก GET /admin/courses

รหัสวิชาชื่อวิชาหน่วยกิตปีหลักสูตรจัดการ
กด “โหลดรายวิชา” เพื่อแสดงข้อมูล

หากชื่อฟิลด์จาก API ต่างจากที่แสดง สามารถเปิดดู JSON ต้นฉบับด้วยปุ่ม “แก้ไข” ได้

แก้ไขวิชาบังคับก่อน

PUT /admin/courses/{year}/{course_code}/prerequisite

โครงสร้าง JSON นี้เป็นเพียงตัวอย่าง ต้องตรวจสอบชื่อฟิลด์กับเพื่อน Backend ก่อนบันทึกจริง

เงื่อนไขการสำเร็จการศึกษา

GET / PUT /admin/graduation-rules/{study_plan_id}

แก้ไขจากข้อมูลที่โหลดได้เพื่อลดความเสี่ยงส่งฟิลด์ไม่ตรงกับ Backend
