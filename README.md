# Project Name

## Project Vision
- ออกแบบและพัฒนาระบบกลางที่รองรับผู้ใช้งานหลายบทบาท เพื่อให้ผู้ใช้สามารถเข้าถึงข้อมูลหลักสูตร ค้นหาและสอบถามข้อมูล ตรวจสอบการสำเร็จการศึกษาจากข้อมูลจริง และบริหารจัดการข้อมูลหลักสูตรตามสิทธิ์ที่ได้รับ

## Primary User
- ผู้ใช้ทั่วไปต้องการที่จะสามารถค้นหาข้อมูลหลักสูตรและสอบถามข้อมูลที่เกี่ยวข้องกับหลักสูตร ผู้ใช้แต่ละกลุ่มมีความต้องการและสิทธิ์ในการเข้าถึงข้อมูลแตกต่างกัน

## Problem
- ผู้ใช้ทั่วไปมีปัญหาในการเข้าถึงค้นหาข้อมูลหลักสูตรที่อยู่แยกกันตามไฟล์หรือตามเว๊บคณะที่แตกต่างกัน ทำให้เข้าถึงข้อมูลได้ยาก อีกทั้งการสอบถามข้อมูลที่เกี่ยวข้องกับหลักสูตรเป็นเรื่องที่ยาก ต้องสอบถามจากเจ้าหน้าที่ด้วยการโทร ผู้ใช้ทั่วไปยังมีปัญหาในการเข้าถึงข้อมูลรายวิชาอีกด้วย เนื่องจากเว๊บมีการบังคับการเข้าสู่ระบบ

## V1 Goal
- กำหนดขอบเขตหน้าที่ของระบบข้อมูลหลักสูตรและการตรวจสอบการสำเร็จการศึกษา พร้อมทั้งระบุความรับผิดชอบของระบบ ผู้ใช้ ระบบภายใน ระบบภายนอก แหล่งข้อมูล การไหลของข้อมูลที่ผ่านเข้าหรือออกจากขอบเขตของระบบ ที่อยู่ในขอบเขตของระบบ

## V1 In scope
- หน้า home 
- หน้ารายละเอียดหลักสูตร
- หน้ารายละเอียดทั่วไป

## V1 Out of scope
- ระบบยืนยันตัวตนและการลงชื่อเข้าใช้ (Authentication / Login)
- การจัดการสิทธิ์และบทบาทผู้ใช้งาน (User Roles / Authorization)
- การแก้ไข/เพิ่ม/ลดข้อมูลแบบ Dynamic ผ่านระบบ (CRUD Operations)
- การเชื่อมต่อกับระบบภายนอกหรือข้อมูลจริงของสำนักทะเบียน
- Chatbot

## External actors / systems
- ผู้ใช้งานทั่วไป
- แหล่งข้อมูลหลักสูตร

## Open questions / To validate
- ข้อมูลหลักสูตร แผนการเรียน รายวิชา วิชาบังคับก่อน เงื่อนไขการสำเร็จการศึกษา ถูกเก็บข้อมูลไว้ที่ไหน
- ข้อมูลสามารถดูได้ตลอดเวลาไหม
- ถ้ากรณีมีหลากหลายเมนูในการดูเช่นข้อมูลหลักสูตร แผนการเรียน รายวิชา วิชาบังคับก่อน เงื่อนไขการสำเร็จการศึกษา ผู้ใช้ควรเริ่มต้นดูตรงไหนก่อน
